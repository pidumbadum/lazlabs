# Lazlabs School Management System

Система управления образовательاцентром: расписание, задания, бухгалтерия.

## Быстрый старт

1. Установите зависимости: pip install -r requirements.txt
2. Запустите приложение: python app.py
3. Откройте в браузере: http://localhost:5000

## Роли
- **Директор** — управление пользователями, группами, расписанием, бухгалтерией
- **Учитель** — расписание, задания, проверка работ
- **Ученик** — расписание, сдача заданий
