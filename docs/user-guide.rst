Руководство пользователя
========================

Вход в систему
--------------

1. Откройте браузер и перейдите по адресу ``http://localhost:5000``
2. Введите логин и пароль
3. Нажмите кнопку "Войти"

.. note::

   Если вы видите сообщение "Неверный логин или пароль", проверьте правильность введённых данных.

Дашборд директора
-----------------

После входа в систему как директор, вы увидите панель управления с несколькими вкладками:

Расписание
~~~~~~~~~~

**Назначение занятия:**

1. Выберите дату и время
2. Выберите группу из выпадающего списка
3. Выберите предмет
4. Нажмите "Добавить"

.. warning::

   Занятия можно назначать только с 08:00 до 18:00. Система проверит конфликты по времени.

**Просмотр расписания:**

Расписание на текущую неделю отображается в таблице ниже формы.

Пользователи
~~~~~~~~~~~~

**Создание пользователя:**

1. Выберите роль (Учитель или Ученик)
2. Введите логин и пароль
3. Заполните имя и фамилию
4. Для учителя: укажите процент от занятия
5. Для ученика: выберите группу и укажите контакты родителя
6. Нажмите "Создать"

**Удаление пользователя:**

Нажмите кнопку "Удалить" в таблице пользователей.

.. important::

   Директор не может удалить свой аккаунт или аккаунт другого директора.

Группы
~~~~~~

**Создание группы:**

1. Введите название группы
2. Выберите учителя
3. Выберите предмет
4. Нажмите "Создать"

Занятия (предметы)
~~~~~~~~~~~~~~~~~~

**Добавление предмета:**

1. Введите название предмета
2. Укажите цену за час
3. Нажмите "Добавить"

**Удаление предмета:**

Нажмите кнопку "Удалить" в таблице предметов.

Бухгалтерия
~~~~~~~~~~~

**Просмотр статистики:**

1. Выберите период (дата начала и конца)
2. Нажмите "Рассчитать"
3. Система покажет:
   - Получено (сумма оплат)
   - Выплаты (деньги учителям)
   - Прибыль (разница)

**Внесение оплаты:**

1. Введите ID ученика
2. Введите ID предмета
3. Укажите дату
4. Введите сумму
5. Укажите количество оплаченных и оставшихся занятий
6. Нажмите "Внести"

Дашборд учителя
---------------

Уведомления
~~~~~~~~~~~

В верхней части дашборда отображаются уведомления:

- **Пропущенные занятия** — занятия, которые должны были пройти, но не отмечены как проведённые
- **Новые ответы** — работы учеников, ожидающие проверки

Расписание
~~~~~~~~~~

Отображается расписание учителя на текущую неделю.

**Отметка о проведении:**

Нажмите кнопку "Проведено" рядом с занятием.

Задания
~~~~~~~

**Создание задания:**

1. Нажмите "Назначить задание"
2. Выберите группу и предмет
3. Введите название и дедлайн
4. Укажите максимальный балл
5. Добавьте описание
6. Нажмите "Создать"

**Проверка работ:**

1. Нажмите "Проверить" рядом с заданием
2. Увидите список ответов учеников
3. Выставьте оценку
4. Нажмите "Сохранить"

Дашборд ученика
---------------

Расписание
~~~~~~~~~~

Отображается расписание группы ученика на текущую неделю.

Задания
~~~~~~~

**Сдача задания:**

1. Найдите задание в таблице
2. Нажмите "Сдать"
3. Введите текст ответа, загрузите файл или укажите ссылку
4. Нажмите "Отправить"

.. note::

   Повторная сдача перезаписывает предыдущий ответ.

**Просмотр оценок:**

После проверки учителем, оценка отобразится в таблице заданий.
