Спецификация предметной области
===============================

Описание системы
----------------

**Lazlabs School** — веб-система управления образовательным центром, автоматизирующая:

- Управление пользователями (директор, учителя, ученики)
- Составление расписания занятий с проверкой конфликтов
- Назначение и проверку домашних заданий
- Финансовый учёт (оплаты, выплаты учителям, прибыль)
- Уведомления для учителей о пропущенных занятиях и новых ответах

Роли
-------------

Директор
~~~~~~~~

**Обязанности:**

- Создание учётных записей учителей и учеников
- Создание учебных групп (привязка учителя к предмету)
- Добавление предметов с указанием цены за час
- Назначение занятий в расписание (дата, время, группа)
- Просмотр финансовой статистики (оплаты, выплаты, прибыль)
- Внесение оплат от учеников

**Ограничения:**

- Не может удалить свой аккаунт
- Не может удалить другого директора
- Не может назначить занятие вне рабочего времени (08:00–18:00)
- Не может назначить занятие, если группа или учитель уже заняты в это время

Учитель
~~~~~~~

**Обязанности:**

- Просмотр своего расписания на текущую неделю
- Создание заданий для своих учебных групп
- Проверка работ учеников, выставление оценок
- Отметка о проведении занятия (обновление статуса ``is_completed``)
- Получение уведомлений о пропущенных занятиях и новых ответах

**Ограничения:**

- Видит только своё расписание (не видит расписание других учителей)
- Может создавать задания только для своих групп
- Может проверять только работы своих учеников

Ученик
~~~~~~

**Обязанности:**

- Просмотр расписания своей учебной группы
- Сдача заданий (текст, файл, ссылка)
- Просмотр оценок и статуса проверки

**Ограничения:**

- Видит только расписание своей группы
- Может сдать задание только один раз (повторная сдача перезаписывает предыдущую)
- Не может изменить оценку после сдачи

Бизнес-правила
--------------

BR-1: Расписание
~~~~~~~~~~~~~~~~

- Занятия назначаются только в рабочее время: **с 08:00 до 18:00**
- Одна группа не может иметь два занятия в одно время
- Один учитель не может вести два занятия в одно время
- Расписание отображается на текущую неделю (понедельник–воскресенье)

BR-2: Задания
~~~~~~~~~~~~~

- Один ученик может сдать задание только один раз
- Повторная сдача перезаписывает предыдущую (через ``INSERT OR REPLACE``)
- Оценка выставляется по 100-балльной шкале (или ``max_points`` задания)
- Статусы задания: ``pending`` → ``submitted`` → ``checked``

BR-3: Бухгалтерия
~~~~~~~~~~~~~~~~~

- **Выплаты учителям** = цена_часа × процент_учителя × кол-во проведённых занятий
- **Прибыль** = сумма оплат − выплаты учителям
- Учёт ведётся по датам (фильтрация по периоду)

BR-4: Уведомления
~~~~~~~~~~~~~~~~~

- Учитель получает уведомление о **пропущенных занятиях** (дата+время ≤ текущему, ``is_completed=0``)
- Учитель получает уведомление о **новых ответах** учеников (статус ``submitted``)

BR-5: Удаление пользователей
~~~~~~~~~~~~~~~~~~~~~~~~~~~~

- Директор не может удалить свой аккаунт
- Директор не может удалить другого директора
- При удалении ученика удаляются все связанные записи (ответы, оплаты)
- При удалении учителя удаляется только профиль (расписание и задания сохраняются)

Сущности и связи
----------------

User (Пользователь)
~~~~~~~~~~~~~~~~~~~

- ``id`` — уникальный идентификатор
- ``login`` — логин (уникальный)
- ``password_hash`` — хеш пароля
- ``role`` — роль (``director``, ``teacher``, ``student``)
- ``linked_entity_id`` — ссылка на профиль (teacher.id_teacher или student.id_student)

Teacher (Учитель)
~~~~~~~~~~~~~~~~~

- ``id_teacher`` — уникальный идентификатор
- ``name``, ``surname`` — имя и фамилия
- ``payout_percent`` — процент от стоимости занятия (по умолчанию 0.0)

Student (Ученик)
~~~~~~~~~~~~~~~~

- ``id_student`` — уникальный идентификатор
- ``id_group`` — ссылка на учебную группу
- ``name``, ``surname`` — имя и фамилия
- ``phone_number`` — телефон
- ``parent_name``, ``parent_phone``, ``parent_email`` — контакты родителя

Lesson (Предмет)
~~~~~~~~~~~~~~~~

- ``id_lesson`` — уникальный идентификатор
- ``name`` — название предмета
- ``price_hour`` — стоимость часа занятия

StudyGroup (Учебная группа)
~~~~~~~~~~~~~~~~~~~~~~~~~~~

- ``id_group`` — уникальный идентификатор
- ``id_teacher`` — ссылка на учителя
- ``id_lesson`` — ссылка на предмет
- ``group_name`` — название группы

Schedule (Расписание)
~~~~~~~~~~~~~~~~~~~~~

- ``id_schedule`` — уникальный идентификатор
- ``id_group`` — ссылка на группу
- ``id_teacher`` — ссылка на учителя
- ``date`` — дата занятия (формат YYYY-MM-DD)
- ``time`` — время начала (формат HH:MM)
- ``is_completed`` — флаг проведения (0/1)

Task (Задание)
~~~~~~~~~~~~~~

- ``id_task`` — уникальный идентификатор
- ``id_group`` — ссылка на группу
- ``id_teacher`` — ссылка на учителя
- ``id_lesson`` — ссылка на предмет
- ``title`` — название задания
- ``description`` — описание
- ``deadline`` — срок сдачи (формат YYYY-MM-DD)
- ``status`` — статус (``active``, ``archived``)
- ``max_points`` — максимальный балл

TaskSubmission (Ответ ученика)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

- ``id_submission`` — уникальный идентификатор
- ``id_task`` — ссылка на задание
- ``id_student`` — ссылка на ученика
- ``grade`` — оценка
- ``submission_text`` — текстовый ответ
- ``submission_file_path`` — путь к загруженному файлу
- ``submission_link`` — ссылка на ответ
- ``status`` — статус (``pending``, ``submitted``, ``checked``)
- ``submitted_at`` — дата и время сдачи

Accounting (Финансовая операция)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

- ``id_operation`` — уникальный идентификатор
- ``id_student`` — ссылка на ученика
- ``id_lesson`` — ссылка на предмет
- ``date`` — дата оплаты
- ``payment_amount`` — сумма оплаты
- ``is_paid`` — флаг оплаты (0/1)
- ``classes_paid`` — количество оплаченных занятий
- ``classes_left`` — количество оставшихся занятий

Сценарии использования
----------------------

UC-1: Вход в систему
~~~~~~~~~~~~~~~~~~~~

1. Пользователь открывает страницу ``/login``
2. Вводит логин и пароль
3. Система проверяет хеш пароля
4. При успехе создаёт сессию и перенаправляет на ``/dashboard``
5. При ошибке показывает сообщение "Неверный логин или пароль"

UC-2: Назначение занятия (директор)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

1. Директор открывает вкладку "Расписание"
2. Выбирает дату, время, группу и предмет
3. Система проверяет:
   - Время в диапазоне 08:00–18:00
   - Группа не занята в это время
   - Учитель не занят в это время
4. При успехе занятие добавляется в расписание
5. При ошибке возвращается сообщение о конфликте

UC-3: Сдача задания (ученик)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~

1. Ученик открывает вкладку "Задания"
2. Находит нужное задание и нажимает "Сдать"
3. Вводит текст, загружает файл или указывает ссылку
4. Система сохраняет ответ (перезаписывает предыдущий, если есть)
5. Статус меняется на ``submitted``

UC-4: Проверка работы (учитель)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

1. Учитель открывает список заданий
2. Выбирает задание и нажимает "Проверить"
3. Видит список ответов учеников
4. Выставляет оценку и нажимает "Сохранить"
5. Статус меняется на ``checked``, оценка сохраняется

UC-5: Внесение оплаты (директор)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

1. Директор открывает вкладку "Бухгалтерия"
2. Заполняет форму: ID ученика, ID предмета, дата, сумма, кол-во занятий
3. Система создаёт запись в таблице ``accounting``
4. Обновляется статистика (общая сумма оплат, выплаты, прибыль)

Ограничения и допущения
-----------------------

- **База данных**: SQLite (не подходит для высоконагруженных приложений)
- **Безопасность**: пароли хешируются, но нет защиты от CSRF (планируется)
- **Файлы**: загружаются в локальную папку ``uploads/`` (не используется облачное хранилище)
- **Уведомления**: только внутри системы (нет email или push-уведомлений)
- **Масштабируемость**: система рассчитана на небольшой образовательный центр (до 500 учеников)

Глосарий
---------

Учебная группа
    Набор учеников, изучающих один предмет с одним учителем

Занятие
    Запись в расписании (дата, время, группа, учитель)

Задание
    Домашняя или классная работа, назначенная учителем

Ответ
    Работа ученика, сданная на проверку

Оплата
    Финансовая операция (внесение денег за занятия)

Выплата
    Деньги, которые учитель получает за проведённые занятия
